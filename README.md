# Video Game Catalog

A full-stack web application built as my final course project.

This project is designed to manage and showcase a catalog of video games through a complete digital experience: an admin backoffice for content management and a guest frontend for browsing and discovering games.

## Project Overview

The goal of this project is to build a complete website focused on the world of video games.

The application is divided into two main parts:

- **Backoffice in Laravel** for administrators
- **Frontend in React** for guest users

The admin area allows authenticated users to manage the catalog data, while the guest area offers a clean and interactive interface to explore the available content.

## Main Features

### Backoffice (Laravel)
- Authentication with Laravel Breeze
- Full CRUD for video games
- CRUD for related entities such as genres or platforms
- Media upload for cover images
- Data management through Blade views

### Frontend (React)
- Display of the video game list
- Single game detail page
- Related information shown clearly, such as genre and other connected data
- Data fetched from Laravel REST APIs

## Database Idea

The project is based on a main entity:
- **Video Games**

And one or more related entities, for example:
- **Genres**
- **Platforms**

This structure makes the project realistic, scalable, and coherent with the course requirements.

## Tech Stack

- **Laravel** for backend, authentication, admin panel, and APIs
- **Blade** for the backoffice views
- **React** for the guest frontend
- **MySQL** for database management
- **JavaScript**, **PHP**, **HTML**, **CSS**, and **JSON** as core web technologies
